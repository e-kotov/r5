Minimal fork prerelease of R5 7.6 for large regions, based on v7.6.1-ek.1. Routing is unchanged.

* Bounding box area limit raised from 10 million to **100 million km²**.
* Web Mercator grid cell limit raised from 50 million to **2,147,483,639** (the largest grid Java can index).
* The grid cell count is now computed in `long` arithmetic, so oversized grids can no longer wrap around and pass.

Passing these limits does not mean a region fits in memory: a street linkage takes 16 bytes per grid cell per mode.
The whole US including Alaska is still rejected because the Aleutians cross the antimeridian.
